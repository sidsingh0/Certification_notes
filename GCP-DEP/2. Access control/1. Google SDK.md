#### Configurations
- We can create configurations based on common usage pattern.
- Example a PROD configuration
- Steps:-
	- `gcloud config configurations create [NAME]`
	- `gcloud config set project [PROJECT_ID]`
	- `gcloud config set compute/zone [ZONE]`
	- `gcloud config set compute/region [REGION]`
	- `gcloud config configurations activate [CONFIGURATION_NAME]`

#### Initial Steps
- First we need to login to the console
	- `gcloud auth login`
- Set default project
	- `gcloud config set project [PROJECT_ID]`
- YOU CANNOT WORK ON GCP WITHOUT THESE 2 STEPS

#### Other commands
- `gcloud init` : guides us through setting up gcloud
- `gcloud projects list`: lists all projects associated to the account
- `gcloud services list`: lists all the APIs/Services enabled in the **CURRENT PROJECT**
- `gcloud projects describe`: provides detailed metadata for projects
- `gcloud compute instances list`: lists all the VM instances in the current project
- `gcloud config configurations create [CONFIGURATION_NAME]` -> `gcloud config configurations activate [CONFIGURATION_NAME]`
