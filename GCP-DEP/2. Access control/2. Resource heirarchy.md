### Projects
- Essentially, resource group
- Lowest level of organization in GCP
- Provides separate IAM access control (for developers) and billing
- Contains resources inside

### Organizations
- Highest level of organization in GCP
- They represent a division, section or an entire organization
- An organization can have multiple projects inside. It centralizes the management of those projects.
- *Organizations are NOT MANDATORY*
- Organizations are ALWAYS tied to a Google Workspace/Cloud Identity Account
- Roles are granted at this level. Ex. A role to access multiple projects from one role. Doing this on project level is cumbersome, since we would have to create roles in each project.
- Billing and access control can also be managed from this level.
- We can view all the resources at once place

### Folders
- Intermediate organizational structure between Organizations and Projects
- *THEY DO NOT TRACK BILLING*
- They are not mandatory either.
- In an organizations, one department might have multiple projects. To organize these projects for a department, we can create a folder for each department.
- They inherit policies and permissions from the parent organization.
- They can be nested. ie. Folder inside folder
