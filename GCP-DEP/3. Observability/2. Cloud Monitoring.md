- Collect, Analyze and Visualize metrics from GCP resources.
- **Real time metrics and alerts**
- Health check/performance for resources
- custom dashboard
- used to be called stackdriver monitoring

### Types of metrics
1. Built-in Metrics
	1. Infrastructure
		1. CPU Utilization
		2. Disk IO
		3. Network traffic
		4. Memory Usage etc.
	2. Application Metrics
		1. Response times
		2. Latency
		3. Request rates
		4. Error Rates
	3. System Metrics
		1. System Load 
		2. Running processses
2. Custom metrics
	1. User engagement
	2. Business transactions
3. External metrics
	1. Multi Cloud metrics (Metric from aws, azure)
	2. On-prem applications integration
	3. On-prem monitoring tools integrations

*Best practice: Use built-in metrics over other types(Custom metrics)*

# Alerts
- Real time alerts that tracks a metric
	- Ex. CPU utlization exceeds 90%
	- Error rate spikes
	- Sudden lower number of users
- Notification sent to:
	- Email
	- SMS/Text
	- Custom(Slack, Pagerduty)

### Monitoring multiple projects
- Centralized monitoring for multiple projects in one place can be set by following:-
	1. Set up cloud monitoring workspace in one project
	2. Link other projects to it through Google Cloud Console
