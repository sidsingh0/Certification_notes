- Central place to see all the alerts and logs generated by our GCP resources.
- Formerly knonw as stackdriver.
- Integrates with Cloud Monitoring for Analytics and Automated alerts.

### Log types:
1. Platform Logs
	1. Generated by GCP services
	2. Ex. Compute Engine, Cloud SQL database etc. logs
2. Application Logs
	1. Logs generated by our application
	2. Userful for debugging and finding errors
3. Audit Logs
	1. Logs all the user and system activities that have security implications
	2. ex. User accessed VM abc

#### Retention period
- Default: 30 Days
- We can set custom retention period too
- We can export logs for longer storage
- Compliance and cost management

### Log sinks
- Export Destination for generated logs, based on specific filters.
- Examples: Error log from GCE -> GCS bucket for long-term storage
- Reasons:-
	- Auditing and compliance
	- If log data is sent to bigquery, we can **analyse** the logs
