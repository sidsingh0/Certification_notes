Windows are used to chunk or group data for analysis
There are 3 patterns:-

### 1. Fixed Windows (Tumbling)
![[Pasted image 20260726031553.png]]
- Each window is of a fixed `duration_length`
- Non-overlapping
- Sequential
- Used for data analytics. 
	- Ex. Calculating the Average over a fixed period of time
### 2. Sliding Windows (Hopping) 
![[Pasted image 20260726032030.png]]
- Each window is of fixed `duration_length`
- There is a fixed `hop_duration` for jumps
- Overlapping
- Used to calculate a metric more frequently and to involve larger amount of time accurately
	- Ex. To calculate average price of stock market but considering past 10 minutes. Since in case of Fixed windows, there is acase that a data point is the first data point in that window. Since there is no other data points in the window the aggregate figure is less accurate. However in case of sliding windows there will always be past 10 minutes of data to consider.

### 3. Session-based Windows
![[Pasted image 20260726032355.png]]
- Windows are defined by the gap of natural inactivity in the data
- If the gap of inactivity is longer than pre set `gap_duration`, a new window is started for that
- If gap duration is never reached, Entire dataset might be considered which might cause issues.
- The length of window is dynamic and no fixed window length like other 2.
- Ex. Google Analytics
