# Method 1: Update pipeline without stopping

- Create an **update job**
- It creates a new job with the same name with a new jobId
- This doesnt interrupt the existing job
- Google Performs **compatibility Check** to ensure smooth transition
	- No data loss if the update is incremental and transformations are compatible with older pipeline
	- If any transformation is not backward compatiblem we need to provide a **transform mapping JSON file** to map old transforms to new one. 

# Method 2: Using Drains for Pipelines Updates
- Use this when unsure about the compatibility OR making major changes (Changing windowing, triggering etc), use the drain option
- It processes all inflight data
- Then pauses pipeline and no new data is processed till the new job starts
- This ensures no data is lost while updation
- Generally **safer option**
- Downside: Temporary pause in processing
