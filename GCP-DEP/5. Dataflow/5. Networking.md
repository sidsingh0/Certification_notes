## Essential Ports
1. TCP 443 HTTPS
	- All dataflow jobs require this
	- Workers use this port to communicate with the service pane, API requests, job metadata exchange
2. TCP 12345
	- Streaming Jobs with no shuffle and streaming engine
	- Facilitates Worker to Worker and Worker to service communication
3. TCP 12346
	- Batch jobs with no shuffle and sreaming engine is not used
	- Facilitates Worker to Worker and Worker to service communication

## Firewall Rules
When using the Dataflow inside a VPC, we need to enable above ports in firewall for egress and ingress

## Exam question
Workers cannot communicate with each other, what to do?
Configuring firewall rules to allow the ports
