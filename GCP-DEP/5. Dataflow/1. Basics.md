### Pcollection & Elements
- PCollection is a distributed dataset which we give as input and get out as output
- PCollection can be understood as a table with rows.
- Each row is called an **Element** and each element has **Attributes**
- In reality each element is distributed over multiple machines. Each machine handles different subset of PCollection.
- PCollections are not single centralized dataset
- We can increase the number of Worker Machines to handle more data. Therefore it is more Scalable and Faster due to parallel processing.

### PTransform
- Transform is any processing operationa applied to data
- PTransform = Pipeline Transform
- It is used to transformations and clean the data

#### Types of PTransforms:
## 1> ParDo:
1. Transform applied to each individual element(row) of PCollection(table)
2. Good for filtering/extracting data.
	1. Ex. Remove all the invalid data.
3. **DoFn**(function inside ParDo):
	1. Custom logic applied to each element as part of the transformation for ParDO
		1. Logic for transformations are written in DoFn

Basically ParDo is a filter function like in py and DoFn is the lamda that describes what to do to current element 
#### Side Input and Side Output
- Side Input: 
	- Supplemental data we need to provide during PTransform. 
	- We can enhance processing logicwith external references
	- Ex. 
		- Lookup Tables
		- Configurations data
- Side Output: 
	- Additional output PCollection.
	- It allows main data flow to continue processing and we can send results to different locations simaltaneously
	- Example:
		- Main Input: Customer records
		- Main Output: Valid customers
		- Side Output: Invalid customer records (saved for later review)
