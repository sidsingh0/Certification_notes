#### Worker Type (workerMachineType setting)
1. General Purpose: Balanced workloads with moderate CPU and memory requirements
2. High memory: Optimized for memory heavy tasks. 
   Ex. Large dataset that requires more memory to process, jobs that load a lot of data in memory
3. High CPU: Heavy processing, encryptions or transformations
4. Preemptible: Lowest cost, but subject to shut down since google can reclaim and allocate them to some one else
   Ex. Jobs that can handle interruptions and can handle shutdowns without major consequences
#### Autoscaling
Adjust number of workers, based on incoming data volume
Does not support vertical scaling
#### Max Workers (maxNumWorkers)
Used with autoscaling
Used to manage costs
Analyze expected workload, set a reasonable limit and monitor it to adjust

#### To improve throughput with Autoscaling enabled
1. Increase maxNumWorkers
2. Change workerMachineType to more powerful
