- Memorystore is GCP's fully managed in memory data store
- best for caching layer (Frequently accessed data)
- Significant application performance increase
- Supports
	- Memcached
	- Redis
- Use case scenarios:
	- Wherever there is frequently accessed data
	- Wherever there is high number of read/writes for localized traffic(persistance is not as important)
