# Memcached vs Redis
- Since memcached was built for scalability, it is the best suited option for variable workloads. Redis on the other hand does not support scaling, so we need to be aware of workload beforehand.
- If the PC carrying memcached is shut down, the data will be lost, therefore it is meant for workloads that can handle non-persistent memory layer, Redis gives us the option to persist our data
- Memcached is preferred for simpler tasks: Database query caching, session caching, 
  Redis has more features, so it is preferred for complex tasks: Leaderboards, real time analytics, Message Queueing etc.
