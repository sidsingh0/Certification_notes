- It is a secure way to connect to Cloud SQL instance
- Since it acts as a proxy between the application and the DB instance, 
	- There is no direct network link between the app and the DB
	- DB instance's IP is hidden from the application
- It also ensures encrypted connection between app and the db
- Authorization happens based on IAM policies.
	- Applications that would like to connect to the DB intances (who have auth proxy enabled), require the ***cloudsql.instances.connect*** role
