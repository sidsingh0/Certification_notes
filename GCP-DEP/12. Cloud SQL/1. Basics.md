- Cost Effective and managed, horizontal scaling depends on the db instance type.
- Lift and Shift migration for PostgreSQL, MySQL
- Also supports SQL Server but with limitations
- Suitable for small-medium datasets
- Suitable for Single Region Deployment (Multi Region -> Cloud Spanner)
- ACID Compliance with strong consistence

#### Max storage capacity : 64 GB
If this runs out we can consider the following:
- Spanner: If we require strong consistency and ACID compliance
- BigTable: If NoSQL is an option, strong consistency and ACID compliance
- BigQuery: If we do not need strong consistency and ACID compliance, OLAP

# OLTP and OLAP
1. Online Transaction Processing
	1. Cloud SQL is designed for OLTP
	2. INSERT, UPDATE, DELETE
	3. Management Systems, E-commerce, Banking
2. Online Analytical Processing
	1. Big Query is designed for OLAP
	2. SUM, AVG, MIN, MAX, COUNT (basically aggregations)
	3. Data mining, Trend Analysis, Business Intelligence etc
