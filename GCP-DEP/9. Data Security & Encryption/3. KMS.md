- Cloud Key Management Services
- Allows us to create, use, rotate and destroy cryptographic keys
- Generally used to comply with industry regulations
### Why choose KMS over GCP's default encryption
- Default encryption is fully managed by google. We have no control over key management.
- Many industries require to have a greater management of these processes.
	- Ex. HIPAA for healthcare
	- Finance
	- Government Agency
	- GDPR in EU
- So generally for compliance

## Customer Managed Encryption Keys (CMEKs)
- Allow organizations to control their own encryption keys rather than allowing google to do so.
- Allow rotation, management and revocation.
- Commonly used to encrypt data in GCS, Compute Engine and Bigquery Datasets

# Other Types of keys
- GMEKs (Google Managed)
- CSEKs (Customer supploed encryption keys) -  Here we bring our own keys and manage them in Google Cloud KMS, (unlike CMEKs where the key is also generated by google)
- Cloud HSMKs (Hardware Security Module Keys) - Using hardware device for extra 
- Tink Keys - Tink is open source cyptographic library. These keys are used within that library for cryptographic operations.
