- When CMEK is compromised, the data has to be re-encrypted with a new key.
- 2 Ways [Important]:
	1.  Cloud Storage
		- Create a new CMEK
		- Transfer the entire data to a new bucket
		- During the transfer provide the new CMEK
		- This way new bucket is encrypted with new CMEK
	2.  Big Query
		- Create a new CMEK
		- Create a new dataset which uses the new key
		- Just copy the data from old dataset to new
		- Since we provided the key during dataset setup, it automatically encrypts the data with new key
		- We can also use different encryption keys at different table levels
