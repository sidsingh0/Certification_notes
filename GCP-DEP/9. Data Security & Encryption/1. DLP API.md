- Tool to discover, classify, and protect sensitive data.
- Automated data recognition, risk analysis, data redaction and de-identification.
- Protecting/Identifying PII, PHI(Personal Health Information) and other sensitive information
- Can act as a standalone API or integrate with other GCP services
- Best used for compliance purposes GDPR, HIPAA etc.

# Data protection methods

### Masking
- Like mask adhaar
- We replace some part of the data with asterisks/other characters while leave some portion visible
- Generally used for verification/analytics/reference purposes, 
  ex. When speaking to customer care, they ask us for last 4 digits of our credit card number to verify if they are speaking to correct person

# FPE (Format Preserving Encryption)
It is used when the data has to remain in a specific format for further processing, but it does not need to be human readable for troubleshooting or analytics.
Note that in the following examples. format is preserved (Credit card no format, email format etc.)
