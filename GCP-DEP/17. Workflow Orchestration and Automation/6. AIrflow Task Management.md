If writing API code inside every callback is too tedious, you can use **Log-Based Metrics**:
1. Your `on_success_callback` or `on_failure_callback` simply prints a structured JSON log message (e.g., `{"status": "SUCCESS", "task_id": "extract_data", "duration": 45}`).
2. **Cloud Logging** automatically ingests this standard log output from your Airflow worker.
3. You set up a **Log-Based Metric** in GCP that scans logs for `"status": "SUCCESS"` or `"status": "FAILURE"`.
4. Cloud Monitoring picks up these log metrics automatically to **populate real-time dashboards** and **trigger alert conditions**.
