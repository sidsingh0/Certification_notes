- Managed implementation of Apache Airflow (Not fully no-ops, Low-ops)
- It offers us a UI to create pipelines
- We only have to configure certain parameters (w.r.t scaling)
- Apache Airflow is a framework to create, schedule, manage and monitor pipelines.
- Modern big data pipelines are often complex:
	- Must create resources in multiple services
	- Complex dependencies between the resources
	- Remove resources when task is completed
	- Central dashboard to manage all the workflows
	- Complex, time based or event drive scheduling

# DAG 
- It is a collection of tasks, organized in a way that reflects their relationship and dependencies
- Some tasks might need completing before the next task begins, others can run in parallel
