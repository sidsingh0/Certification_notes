1. Composer Admin: Full access to create, update & manage cloud composer environments.
2. Composer Developer: Deploy, Modify & manage DAGs inside the environment. (So not the entire service access, just that specific environment without environment settings)
3. Composer User: Run and schedule DAGs without modifying the environment
4. Composer Viewer: View env and config
5. Composer Environment and Storage Accessor: Access cloud storage bucket that is used by the Cloud Composer. Just for managing DAGs, files, logs.
6. Composer Worker(Service Accounts): Permissions to run a composer environment VM. 
**All roles granted at Project level**
