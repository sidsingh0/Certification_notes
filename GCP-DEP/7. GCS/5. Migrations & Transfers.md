# Storage Transfer Service
- Allows us to transfer data from on-prem/other cloud providers
- Uses internet (High bandwidth, atleast 100 Mbps, 1 GBps is preferred)
- We can automate/schedule transfers from different sources
- Upto hundreds of terabytes, else use transfer appliance

# Upload using gcloud/gsutil
1. gcloud
	1. For a single file:
	   `gcloud storage cp [local_path] gs://[bucket]/`
	2. For directory
	   `gcloud storage cp -r [local_directory] gs://[bucket]/`
2. gsutil
	1. For a single file:
	   `gsutil cp [local_path] gs://[bucket]/`
	2. For directory
	   `gsutil cp -r [local_directory] gs://[bucket]/`

# Partitioning [Important]
- If the file is large, it might help to break it into small parts, and then create concurrent upload jobs.
- gsutil(parallel composite uploads), gcloud, storage transfer service
	- `gsutil -o "GSUtil:parallel_composite_upload_threshold=100M" cp large_file.csv gs://[bucket_name]`

# Compression and Decompressive Transcoding[Important]
- *Compressing the file can greatly reduce upload times and storage costs*
- Usually not necessary
- *Decompressive transcoding:* GCS automatically decompresses gzip-compressed files before serving them, while storing it in its compressed form

# 403 error
