# Storage Location Options
1. Regional Storage
	- Cheapest
	- When we need to keep data in one region. (ex. Compliance)
	- Fast retrieval speeds in the same region
2. Dual Region Storage
	- More durability and availability than regional storage
	- Good for disaster recovery
3. Multi Region Storage
	- Good for Global Needs with low latency
	- Expensive
	- Continental access (EU, US, Asia)
	- Highest Availability
