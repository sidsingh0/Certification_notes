There might be an exam question: What level to set the role at? we do not need to set roles at all the levels, setting them at the higher levels automatically propagates to lower levels

# IAM Roles
- Storage Admin: Full access over GCS
- Storage Object Admin: Allows us to **manage** objects in GCS buckets
- Storage Object Creator: Allows us to **upload** objects to GCS buckets
- Storage Object Viewer: lets us read objects in GCS buckets
- Storage Legacy Bucket Reader: lets us read bucket metadata and bucket data

# Signed URLs
- same as amazon
- no authentication required
- ***403 error with signed URLs***[Important]
	- Signed URL is no longer valid
	- Increase the validity period for the signed URL

# Static Websites
- same as amazon
- we need to set "Content-Type" metadata(ex. audio/mpeg) to ensure direct playback in the browser instead of prompting a download
