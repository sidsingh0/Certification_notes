- This connector links Spark(Often running in DataProc) with BigQuery
- We can process the data in Spark and then Store it in BigQuery
- So our data processing pipelines can use both Spark and BigQuery
- Exmaple:
	- Let's say we process and clean daily logs on Spark, using the connector, we can write the data directly to BigQuery. This allows the analytics team to query the data.
	- Let's say we are enriching customer data from external sources in Spark. We can write the enriched data directly to BigQuery using the connector.
