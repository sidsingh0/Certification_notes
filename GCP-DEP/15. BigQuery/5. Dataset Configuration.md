### Dataset expiration setting
- We can remove the tables after a certain period.
- Dataset Expiration:
	- We can set a default expiration time for all the tables in that dataset, after the time is reached, that table is deleted
	- Helps manage storage, data lifecycle
- Table Expiration:
	- Overrides dataset expiration time
	- We can specify the expiration time for individual table
