# External Tables
- Allows us to query data stored outside of BigQuery. (Ex. Cloud Storage)
- *This allows us to query data without moving it.*
- Reduces data duplication and storage costs.
- Supported sources:
	- Cloud Storage
	- BigTables
	- Google Drive

# Fedarated Queries
- Allows us to query other GCP Databses 
	- CloudSQL, 
	- Spanner, 
	- AlloyDB
- We recieve the results as **temporary tables**
- We do not need to move the data to BigQuery!
- **EXTERNAL_QUERY** function is used.
- *We use the external DB's SQL Dialect instead of BigQuery's SQL dialect*.
