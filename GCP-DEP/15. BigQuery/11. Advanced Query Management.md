### Standard View
- These are the most common type of view.
- They don't really store any data. They are virtual.
- So, everytime we run a query, it is computed.
- Therefore:
	- It is expensive for computation
	- It is cheaper for storage
- Use cases:
	1. When the view is accessed infrequently (Less computation)
	2. When storage costs of are higher than the compute costs. (No storage)
	3. When view requires less computation
	4. *Real-time reflection without frequent refreshes*

### Materialized Views
- Precomputed and cached view of the data
- *Most cost effective solution for frequently accesed data in large datasets.*
- Reduces computational charges, by only computing once.
- Therefore:
	- Cheaper compute
	- Larger storage costs (Unlike standard view which doesnt really store any data)
- Use cases:
	1. When the view is accessed very frequently
	2. When the storage costs are lower than compute costs	
	3. *Real-time reflection without frequent refreshes* IS NOT REQUIRED


### Authorized Views
- Used for access control.
- This view allows the user to see a result of the query, without having access to the actual tables.
- Restricts access to sensitive data.
- Control data visibility
- VERY USEFUL in multi cloud environment
