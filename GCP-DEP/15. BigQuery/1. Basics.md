- Fully managed and serverless database (no-ops)
- Great for storage and analysis (It can house petabytes of data)
- Auto-scales both storage and compute
- *Accepts both batch and streaming loads
- GCP's data warehouse solution
- Extremely popular.
- Can use standard/legacy SQL
	1. Standard SQL (**Recommended**):
		- It is based on modern SQL Standards, that we are familiar with
		- Supports nested data
		- It is more verbose and explicit, therefore easier to understand and debug.

	2. Legacy SQL (**Only for legacy systems**):
		- Also known as Big Query SQL
		- Since the language is not the standard sql and a custom one, it is tougher to understand.
