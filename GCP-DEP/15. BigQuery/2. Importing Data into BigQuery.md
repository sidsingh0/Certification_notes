### 4. BigQuery Streaming API vs BigQuery Storage Write API

| Streaming API                                                                                                                                   | Storage Write API                                                                                            |
| ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| At-least once delivery, meaning that                                                                                                            | Exactly once delivery                                                                                        |
| There might be duplicates                                                                                                                       | There will not be any duplicates                                                                             |
| Good for streaming data and real time processing where immediate availability of the processed data data is more important than higher accuracy | It is good for the data that requires maximum accuracy and  where some delays in availability is acceptible. |
| Low latency                                                                                                                                     | Higher latency                                                                                               |
| Low Throughput                                                                                                                                  | Higher Throughput                                                                                            |
| Ex. Customer sentiment analysis                                                                                                                 | Ex. Financial Analytics                                                                                      |

### 5. Importing data from Apache Hive into BigQuery
- Apache Hive Data (Parquet, Avro, ORC) can be easily loaded into BigQuery
- Optimizes storage and processing, since bigQuery is serverless, we only pay for what we use. Better than maintaining a dedicated Hadoop Cluster.
- We can also keep the data in CloudStorage and query the data as external table.

### 6. Importing from Teradata 
- We use **FastExport and JDBC** to import data from Teradata
- JDBC is the standard JAVA library for applications to interact with SQL Databases
- FastExport is teradata's high speed tool to export data effeciently
- We can use with or without data transfer service
