It provides the following feature:-
1. Resource utilization and Job Status (Things like the CPU Utilization etc.)
2. Slot Management
	1. BigQuery uses a concept of Slots to allocate computing resources to a job.
	2. Admin console allows us to manage our slot allocations
	3. Therefore we can allot appropriate amount of compute to the job.
3. Policy Taxonomies
4. Query `INFORMATION_SCHEMA` to get a sense of job performing. [IMPORTANT]
	1. ![[Pasted image 20260802053642.png]]
	2. It is useful for understanding usage patterns and optimizing performance
	3. `INFORMATION_SCHEMA` is a standardized set of metadata of datasets, tables, columns, jobs etc.
	4. *EXAM QUESTION: Something is going wrong. How to figure out? Use Information Schema.*

### Viewing errors related to the jobs
- Apart from Cloud Logging, BigQuery also allows us to view the errors related to jobs (ex. Ingests, ad-hoc and scheduled queries)
- *In case a job fails, this is the first place to look for.* 

### QuotaExceededError
- Generally happens when a resource quota has exceeded.
- We should first identify which specific quota was exceeded 
	- No of DML queries per day
	- Amount of imported data
- Review the current quota usage in GCP console
- Leverage the `INFORMATION_SCHEMA`
