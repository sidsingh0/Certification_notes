- Looker Studio integrates directly with BigQuery.
- Whenever we get a result from a query in BigQuery, we can use the results in Looker Studio for exploration.
- We can also import the BigQuery tables as data sources in LookerStudio. We can also write queries and views there itself.  
- Looker studio is a free visualization/dashboard tool. It can create dynamic charts from our data.
