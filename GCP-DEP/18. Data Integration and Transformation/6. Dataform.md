- Dataform is used to manage and automate SQL-based transformations.
- Features:-
	- SQL-based transformations
	- Version control integration
	- Workflow Automation
- It provides a collaborative environment for teams, so they can work together to create SQL based transformations.
- Seamless integration with BigQuery

#### Dataform is optimized for ELT
- Transformations happens after the data has been loaded into the database(ex. BigQuery)
- **If we require ETL, choose things like DataFlow**

#### Exam Question
If ELT is mentioned and Dataform is an option, choose it.

# Assertions in Dataform
- Assertions are used to validate data quality in a pipeline 
- They can check for qualities like not null, uniqueness and other data integrity issues.
	- For example: Assertions can identify null values in important fields(like ID)
	- This will cause the validation to fail and inform us, this way we can catch issues early on.
