- **Service used for change data capture, CDC, and data replication.**
- It used to be a part of Dataflow before
- Usecase: Suppose we have an on-prem database that we want to replicate to GCP, we can use Datastream for that.
	- Ex. If we want to replicate an on-prem Oracle db to BigQuery, for analytics, we use Datastream.
