## Separate VPCs in each project
- Works at network layer, not in service layer
- No peering or routing connections between each projects vpcs
- Generally used when:
	- Project is for different departments
	- Can be helpful for different compliance requirements

## VPC Service controls
- Works at the service layer
- Creates a security parameter around each project preventing data leakage.
- Resources in one project cannot communicate with resources in other project
