# Subnets
- Defined at region level
- User specifies the CIDR IP Range
	- Subnet IP range needs to stay within the boundary of the VPC's IP Range
	- Subnet IP ranges cannot overlap with each other in the same VPC
	- DO NOT USE 0.0.0.0/0, it is the default route for all the IP addresses
- *In case we run out of IP addresses in our subnet, we can expand our subnet's IP range without deleting it!*
