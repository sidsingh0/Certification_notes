- Dataproc is a managed, on-demand version of Apache Hadoop and Spark.
- It is used for Batch Operations

## Dataproc Architecture
![[Pasted image 20260727233233.png]]
- There is one master node. Components:
	- HDFS NameNode: 
		- It contains the metadata and location of files that are distributed throughout the slave nodes.
		- Necessary for fast retrival of data(since it has mapping of data location)
	- YARN Resource Manager: 
		- It gets tasks and breaks it down into smaller chunks and distributes it to slave nodes.
		- Necesary for parallel processing and resource utilization
- There are multiple slave nodes, these nodes perform the actual tasks. Components:
	- HDFS DataNode
		- Responsible for actual storage and replication of the data
		- Data is distributed and replicated across nodes for fault tolerance and redundancies
	- YARN NodeManager:
		- Local execution of tasks
		- Ensures that the tasks are executed as close to data as possible

## MapReduce
- Allows distributed systems to process large datasets effeciently
- Phases:
- In case of word count:![[Pasted image 20260727235345.png]]
- **Split Phase:** The dataset is split and distributed across different DataNodes in the cluster.
- **Map Phase:** Processes each data chunk locally, converting the data into intermediate key-value pairs at the DataNode level.
- **Shuffle Phase:** Collects, groups, and sorts the intermediate key-value pairs so that all values for a given key are sent to the same reducer.
- **Reduce Phase:** Combines and summarizes the grouped data to produce the final result.

## Apache Hive Data
- It was created to run SQL like queries on the data stored inside the HDFS
- It is the data warehouse inside the Apache ecosystem.
- Commonly appears in migration to cloud scenarios
- **Popular format is Parquet and Optimized Row Column(ORC)**
- **Dataproc effeciently runs Hive Queries on managed Hadoop clusters**
- Hive data is generally stored in Cloud Storage, and from there it is brought into BigQuery(as external tables) or Dataproc(Cloud Storage Connector)
- Choose Bigquery for analytics and Dataproc for Hadoop like system
