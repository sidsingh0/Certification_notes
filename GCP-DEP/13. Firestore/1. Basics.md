- Firestore is a NoSQL OLTP database
- ACID compliant
- Fully managed, Serverless, No-ops
- Multi region access is available
- Real time synchronization of clients
	- In **Cloud Firestore**, **real-time synchronization** is a core capability that allows client applications (such as web, iOS, and Android apps) to stay instantly updated with database changes **without needing to manually poll** the server.

# Where not to use Firestore
1. Do not use for OLAP needs
	- You can use BigQuery, BigTable, Spanner for your OLAP needs.
2. Not meant for extreme scale (10 million or more read/writes per second)
3. Do not use for 
	1. Unstructured data - Use GCS instead
	2. Semi structured data which doesnt have strong consistency needs/ACID compliance needs - Use BigTable
4. Do not use if migrating from Relational Database
	- Use BigQuery/CloudSQL
5. Do not use if you need near zero latency. 
	- Use in-memory data store - Redis
