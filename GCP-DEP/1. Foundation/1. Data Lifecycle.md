### 1. Ingestion Phase
1. Pub/Sub: 
	1. Used for real-time streaming data. (continously generated events)
	2. ex. User interactions on a website
2. Dataflow:
	1. Can be used in real-time or batch mode
	2. For ETL platforms
3. Cloud IoT Core: Useful for IOT devices
4. Application Logs: Useful to check the System behaviour 
5. Cloud Storage: 
	1. Batch Ingestion
	2. Generally used for unstructured database.

Transfer services:
1. Transfer applicance: 
	1. Physical appliance for securely moving large amounts of data
	2. Specifically for cloud storage
2. Storage transfer service: Used for migration from on-premise/other cloud environments to cloud
3.  Bigquery data transfer serivce: Used to migrate external data directly into bigquery

### 2. Storage Phase
Reliable/Accessible
1. Cloud Storage: 
	1. Great for storing backup, images, text data
	2. Very reliable for long term storage
2. BigQuery: 
	1. Serverless data warehouse
	2. Used to store large volumes of structured data
	3. Used for analytic workload: fast queries on large datasets
3. Bigtable:
	1. For NoSQL storage
	2. Wide column
	3. Large scale/time series data
4. Cloud MemoryStore:
	1. Low latency access since data is stored in-memory
	2. Fully managed
	3. Useful for caching
5. Cloud SQL: Structured transactional database
6. Cloud Spanner:
	1. High consistency/availability 
	2. GLOBAL
7. Firestore
	1. Fully managed document database

### 3. Process stage
Transform, clean and enrich data
1. Dataproc
	1. Managed hadoop spark/hive
	2. Large scale data processing
	3. Distributed computing
	4. ETL Processing
	5. Can manage structured and unstructured data
	6. Batch data -> divide into smaller jobs
2. BigQuery
	1. Run transformations on database directly within the warehouse
	2. Uses SQL
	3. Aggregations, Joins, Normalization
	4. Because of this, we can prepare the data for analysis without moving it to a separate system.
3. Cloud Data Fusion
	1. Visual UI
	2. To manage/build pipelines
	3. Simplify orchestration of ETL/ELT workloads
4. Data loss prevention API
	1. Helpful for identify, classify and protecting sensitive data
	2. Credit card nos, PII
5. Data Flow
	1. Supports both batch and streaming 
	2. Highly versatile
	3. Ideal for large scale data transformation
	4. Managed Apache Beam
6. Dataprep
	1. Interactive data prep tool
	2. visual exploring and cleaning data
	3. no code
7. Cloud functions
	1. Lambda (Event driven data processing)
	2. Transforming data on the fly as part of the workflow
8. Cloud composer
	1. Orchestrate data transformation workflows
	2. Automates and schedules tasks
	3. Batch data 

### 4. Analyze and extract value stage
1. BigQuery
	1. Execute SQL queries
	2. Large dataset and fast queries
2. Looker: Transform analyzed data into interactive dashboard
3. Dataproc: Advanced analytics
4. Dataflow: 
	1. Real time data pipelines
	2. Generate real time insights
	3. Parallel processing
5. Cloud Dataprep: 
	1. User freindly UI for preperation and transformation of data for analysis
	2. However, we can also use this for analysis
6. Bigtable
	1. High throughput
	2. Low latency and time series applications
7. Vertex AI
	1. Apply ML models to data
	2. Using Vertex AI workbench, users can create Models and run analysis using jupyter notebooks
	3. Predictive analysis

### 5. Governance
1. Cloud IAM:
	1. Authorization
	2. Least privilege
2. Cloud Logging:
	1. Maintain records
	2. Compliance due to audit trail
3. Data catalog
	1. Metadata management
	2. Useful to discover data
4. Dataplex
	1. Unify data governance between data lake and warehouse
	2. Automated policy enforcement
5. Data loss prevention API
6. VPC: secure network
7. Org Policy service:
	1. Organization level policies
	2. Centralized governance
	3. Data integrity throughout the cloud resources
8. KMS:
	1. Manage encryption key securely
		1. Control encryption key lifecycle
