# Implement Start virtual machine on connect
- Leaving VM running for long times can increase costs.
- We can allow auto shut down on disconnect using GPOs to let machines shut down on logout.
- To move the machines from deallocated state to running when user signs in, we can use `start vm on connect feature`
- This has a pre requisite, we need to assign `Deskop Virtualization Power On Contributor role` to `Azure AVD service`
- We can do this via Subscription > IAM > Create a role assignment
- Only con: Increases login time for users
