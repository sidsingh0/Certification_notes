### Pooled Host Pool
- Multiple users share session hosts.
- Load balancing determines which VM is used.
### Personal Host Pool
- One user gets their own dedicated session host VM.
- User always reconnects to the same VM.

## Assignment Types
### Automatic Assignment
```
User connects -> Gets first available VM -> VM becomes assigned to that user **permanently**
```
- Assignment occurs automatically on first connection.
- Most common setup.
### Direct Assignment
```
Admin manually assignsUser → Specific VM
```
- Administrator selects exactly which VM a user can access.
- User can access only that assigned VM.
 
---
## Creating Personal Host Pool
During Host Pool creation:
```
Pool Type = Personal
```

Choose:
```
Automatic Assignment or Direct Assignment
```
NOTE: User must be assigned to an Application Group to access the AVD

___
## Unassigning Users
Before unassigning:
- User session must be logged off.
- VM must not have an active session.
