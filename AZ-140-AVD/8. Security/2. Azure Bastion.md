# WDAC
- Windows Defender Application Control
- It manages which applications are allowed to run on windows
- Since our AVD environment will have a lot of users, shared session hosts and corporate data, we cannot allow our users to download random softwares (crypto miner, malware etc.)
- Can allow or deny based on:
	1. Digital Signatures (Microsoft signed = Allow, Unknown publisher = Deny)
	2. Application reputation (widely trusted apps = allow)
	3. File path (C:/Program Files = allow, c:/users/user/downloads = deny)
- **MODES**:
	- Audit mode in WDAC logs only the violations, doenst actually block anything
	- Enforcement mode actually blocks apps
	- First we should audit -> review logs if we have any tools which a lot of people use or our in house tools -> enforcement rules

### Difference between Applocker and WDAC
- WDAC 
	- is a big organization wide security
	- All session hosts
	- All servers
	- Entire company etc.
	- Helpful for creating a strong baseline
- Applocker
	- Fine-grained
	- Apply to
		- Sales dept
		- HR dept
		- Specific users
		- Specific groups
- Microsoft recommends using both, first deploy WDAC for baseline and then fine grained department wise rules using App Locker
