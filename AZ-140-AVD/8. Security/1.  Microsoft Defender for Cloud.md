# Microsoft Defender Antivirus
- This antivirus has to be shared with all the computers in our session pool
- Recommended scan configuration: Daily Quick scan for all the PCs
- Now, since new viruses keep coming, we need an updated list of Virus definitions, Malware signatures, Threat Intelligence data, this is called **Security Intelligence Updates**
- Steps to centralize this Antivirus:
	1. On our domain controller server (DC), we create a central repository of these updates.
	   It downloads: defender definitions and security intelligence and stores them in a folder(C:\wdav-update)
	2. Next, we share the folder over the network as (\\\DC\wdav-update) with only read access to session hosts
	3. Verify connectivity by opening \\\DC
	4. Now, create a GPO
	   Policy: Define security intelligence location for VDI clients
	   Target: \\\DC\wdav-update
	   After this step, all the sessions hosts know, to get their updates from here instead of downloading the updates from internet one by one
	   **Therefore network bandwidth is saved**
	5. Also configure scheduled scans using policies: **daily quick scan**
	6. Create an OU: Session hosts, and move computers inside it
	7. Now link the GPO to that OU

# Network Security
- All our AVDs are on the same network
- NSG is a service in azure that provides IP filtering (based on destination, source, ports, protocols)
- VM has a NSG created by default
- IMPORTANT: **In case of our session hosts VM, they dont have NSGs associated to them, instead we apply NSG to the entire subnet**. It would be too difficult to apply 50 NSGs to 50 VM instances.
- For RDP Shortpath we need to allow inbound port 3390 to be accessible as well as 443 inbound. Source port does not matter. We can associate this to our ACD subnet.
- One very important note, when we make the subnet only allow 443 and 3390, and we might lose access to our, Domain controller's UI, which is also inside the subnet but uses RDP at port 3389. 
- So we create a record with the following values:
	- Destination IP: Private IP of DC
	- Destination Port: 3389 RDP
	- Inbound IP: any
	- Inbound port: any
- **In production NEVER EXPOSE RDP since its not secure like shortpath RDP**, in that case, use:
	- Bastion server
	- VPN gateway
	- Express route
