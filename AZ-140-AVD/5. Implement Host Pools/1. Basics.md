- We need to make sure, in order for session hosts to join our domain, the vNET's DNS setting should point to our DNS
- DNS should be pointing towards the DC, whether its in cloud, or on-premise(connected using VPN or expressRoute)
- We can also synchronize our users to Azure AD

Steps to enable AVD
1. Go to AVD
2. Create a new host pool
3. Load balancing algorithms
	1. Breadth-first: 10 users 10 available desktops = 1 to 1
	2. Depth-first: 10 users 10 available desktop and 1 desktop can carry 5 users = 8 Desktops unused, 2 used to completely
4. In the VM creation section, make sure name prefix is not more than 15 char long (For legacy support)
5. Allow inbound RDP HTTP and HTTPS
6. We can add the VMs to domains by providing user id password and domain name and OU(if OU is not mentioned, default is used)
7. After creation is complete, we go to application group for the AVD -> Manage Assignments -> Add user
