Resource to store logs: **Log analytics workspace** and **Storage Account**
Then go to Host Pool > Diagnostic Settings > Send log data to Log analytics workspace and/or storage account
Do the same for session hosts too. Agent gets installed on the VM in this case.

The flow here is Logs -> Storage -> analyze,
but if we want to see logs in real time, we need to use Azure Monitor
Go to VM -> Logs
Azure monitor logs are written in KQL

Workbooks in Azure allow us to save just the data we want and visualize it. For example, if we want to see CPU utilization, creating Workbook will only store that data, but if we do that using log analytics, we will have to save the entire data.

Azure Advisor
Collects information about all our resources and licenses
It also gives us score taking into account things like operations, security etc.
It also allows us to create alerts, depending on severity level(ex. high impact performance alert)
This alert then triggers an action group, which we can trigger to send us emails
Action group has:
- Notification (email, sms)
- Actions (Run azure functions, scripts etc etc)
