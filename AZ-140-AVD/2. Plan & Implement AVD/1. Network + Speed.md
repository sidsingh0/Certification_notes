- By default bandwidth required for virtual desktop is around 237 Mbps
- However, RDP uses various technologies, caching, compression and lowers it;.
- H.264/AVC 444 mode reduces bandwidth usage
- RDP uses dynamic bandwidth allocation (reduces frame rate resolution codec etc based on network requirements)
- We can also set throttle rate to set bandwidth that can be used.
