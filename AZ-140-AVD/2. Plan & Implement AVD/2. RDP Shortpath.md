Azure hosts AVD infra for us.
- RD Gateway allows us to connect to the infrastructure. It has a public IP address.
- RD Broker: Session Hosts (Multiple AVD) can connect to the broker. It also load balances between desktops.
- RD Web allows us to connect to Remote Desktop Session using a web browser
So, the flow is we establish a connection using RD gateway and then directly connect to session host using RDP Shortpath(Over UDP 3390)

#### Methods of authentication:
- Azure AD
- On-premise AD by using Azure AD Connect

#### Supported Networks
- Managed Networks (VPN, ExpressRoute)
- Public Networks (Internet)
#### QoS
Shortpath allows QoS: 
- Packets are tagged with higher priority therefore more bandwidth is allotted to these RDP Packets. (Bi directional: Client + Session Host)
- It improves AVD traffic
