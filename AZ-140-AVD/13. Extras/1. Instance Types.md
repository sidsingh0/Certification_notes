### B-Series (Burstable)
- **What it is:** **Economical, burstble performance.**
- **How it works:** These VMs run at a low baseline of CPU performance when idle and accumulate "CPU credits." When workloads spike, the VM uses those credits to "burst" up to 100% CPU performance.
- **AVD Use Case:** Ideal for **light workloads, testing, or personal host pools used infrequently**. For example, an IT admin's jump box or a sandbox desktop environment where users aren't typing or processing heavily all day. Do not use this for heavy multi-session host pools, or users will experience severe lagging when credits run out.

### E-Series (Memory Optimized)
- **What it is:** **High memory-to-CPU ratio.** * **How it works:** These VMs offer massive amounts of RAM relative to the number of virtual CPUs (vCPUs) assigned.
- **AVD Use Case:** The absolute **gold standard for multi-session AVD host pools** (such as Windows 10/11 Enterprise Multi-session). When you have dozens of users sharing a single virtual machine host, they will rapidly consume RAM via web browsers (like Chrome or Edge) and office applications long before they max out the CPU.    

### F-Series (Compute Optimized)
- **What it is:** **High CPU-to-memory ratio.**
- **How it works:** These feature powerful, fast processors but carry a relatively low amount of system RAM.
- **AVD Use Case:** Great for **heavy, processing-intensive single-user workloads**. Think of data analysts running intense mathematical modeling, local code compilation, or batch processing tools that require raw computational power but don't require hundreds of gigabytes of RAM.

### N-Series (GPU Enabled)
- **What it is:** **Graphics Processing Unit (GPU) specialized.**
- **How it works:** These VMs are equipped with dedicated NVIDIA GPU hardware hardware virtualization (NVenc/NVdec) directly inside the Azure host.
- **AVD Use Case:** Essential for **graphic designers, CAD engineers, video editors, or 3D rendering specialists**. If your AVD users are running software like AutoCAD, Adobe Premiere, or ArcGIS, standard CPU rendering will crawl to a halt; they require an N-Series VM to handle the graphical hardware acceleration.

### A-Series (Entry-Level / Legacy)
- **What it is:** **Low-cost, basic compute.**
- **How it works:** This is an older, legacy tier in Azure offering basic, entry-level CPU and memory configurations with no performance guarantees.
- **AVD Use Case:** **Rarely, if ever, used for modern AVD.** They are typically used for basic development sandboxes, low-traffic test servers, or legacy code repositories. They lack the IOPS (disk performance) and processing efficiency required to deliver a smooth user interface experience on a virtual desktop.
