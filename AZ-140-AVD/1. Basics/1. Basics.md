- To connect our Azure AD(which is in the cloud as PaaS) with Domain Controller(in our network), we use **Azure AD connect**
- Azure AD connect can only sync credentials from DC to Azure AD(Entra ID) outwards

#### To add users
- Inside our Domain contoller > Start > Tools > Active Directory Users and Computers
- Create an Ornganizational Unit(OU)
- Inside the OU, create a user
- This user can belong to several groups for permissions,
	- For the user to be an admin, we can assign Enterprise Admin and Schema Admin group to the user.

#### To setup domain controller's Azure AD connect
- Inside the DC's VM download Azure AD connect software from the browser
- We can specify authentication method during the setup, such as Password Hash, SSO.
- We need to add an account that can sync DC's AD with Cloud's EntraID
