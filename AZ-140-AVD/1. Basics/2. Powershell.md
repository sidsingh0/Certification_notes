- Services:
	- `Get-Service`: List services
	- `Start-Service -Name <service-name>`
	- `Stop-Service -Name <service-name>`
	- `Get-Service -ComputerName CLIENT68`: List services on CLIENT68 computer that is running winrm(Windows remote services)
	- `Enter-PSSession -ComputerName CLIENT69`: Run PS commands inside another computer
- Process
	- `Get-Process`
	- `Get-Process -ComputerName CLIENT1,CLIENT2,CLIENT3 | out-file C:\process.txt`
		- `|` helps us output the results to a file
- For help, `Get-help <Command>`
- Open a file in notepad: `Notepad <path>`
- Create a variable like this:
	- `$computername=sid
	  `Get-EventLog -LogName Security -ComputerName $computername -Newest 10 | Format-List | Out-File C:\security_log.txt`
	- The variables are dynamically-typed (Auto recognize string and number)
- Open integrated scripting environment(code/script editor): `ise`

Some commands are not inherently available in our PC (ex. Azure related commands)
We have to get those commands,
Commands are generally published as modules in Powershell Gallery website
We can search for modules there (like pip)

1. `Install-Module -Name Az -Force -AllowClobber`
2. `Get-Command -Verb connect`: Lists all the commands with connect word

#### AD Specific Commands
- Get users in AD
	- `Get-AzADUser`
- Create a new user in Azure AD
	- `$password = ConvertTo-SecureString -String "****" -AsPlainText -Force New-AzADUser -DisplayName $uname -Password $password -AccountEnabled $true -MailNickname $nickname -UserPrincipalName $upn`
	- UserPrincipalName is basically the email type username with the custom domain we might have registered in our Azure Account.
	- Ex. sidsingh@jvsh.com
	- Useful for creating multiple accounts at once
