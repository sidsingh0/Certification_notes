## 1. OneDrive in AVD
### What is the issue?
AVD multi-session hosts allow many users to log in to the same VM simultaneously.
Standard OneDrive wasn't originally designed for this scenario.
### What is the solution?
Install the **OneDrive Sync App** that supports multi-session environments.
### Exam takeaway
Know that:
- OneDrive is supported in AVD multi-session.
- The OneDrive Sync App should be installed.
- Installing it in the **golden image** is a common best practice.
- Users can then sync files normally across devices.

## 2. Microsoft Teams Optimization
### Why is optimization needed?
Without optimization:
- Audio and video processing occurs on the session host VM.
- Higher CPU and bandwidth consumption.
- Poor meeting experience.
With optimization:
- Audio/video processing is redirected to the user's local device.
- Better Teams call quality.
- Lower load on AVD hosts.
### Exam takeaway
Know that:
- Teams supports AVD.
- **Media Optimization** improves audio/video meetings.
- Audio and video processing happens locally on the client device.

## 5. Golden Image Best Practice
This is probably the most testable point.
### What is a Golden Image?
A preconfigured VM image containing:
- Microsoft 365 Apps
- OneDrive Sync App
- Teams
- Corporate settings
- Security configurations
### Why use it?
Every new session host gets the same configuration.
### Exam takeaway
When deploying many session hosts:
✅ Install required applications in the golden image before deployment.
