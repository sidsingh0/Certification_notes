# MSIX
### Easier Updates
Old way:
```
Update app -> Update golden image -> Redeploy hosts
```

MSIX App Attach:
```
Update package once -> Everyone gets new version
```

### Digitally Signed
What is required before deploying an MSIX package?
Answer: ✅ Digital signature / code-signing certificate

- Applications are attached dynamically instead of installed locally.
- Reduces image management complexity.
- Works well with pooled host pools.
- Applications can be centrally stored.
- Similar concept to FSLogix, but for apps instead of profiles.

## What is an Application Group?

- An Application Group controls:
```
Who can access Which desktops/apps
```
- Without an Application Group: ❌ Users cannot access AVD resources.
- Users must be assigned to the Application Group.

- Types
	1. Desktop Application Group: User gets full windows experience
	2. RemoteApp Application Group: User gets access to only application and not entire desktop.

- A Host Pool can have:
```
1 Desktop Application Group
```
but can have:
```
Multiple RemoteApp Application Groups
```

#### Workspace
- Workspace is used to group multiple application groups together.
- Since user might want to access multiple application groups at once, user subscribes to workspace which contains multiple application groups
