# Azure Image Builder
- It is a bit pain to set up but easier after setup
- A service that automatically creates VM images in Azure.
- Uses:
    - PowerShell
    - Azure CLI
    - JSON templates
- Helps create standardized images repeatedly.
- Useful when you need many identical virtual machines.

#### Managed Identity for AIB
A special Azure identity used by Azure Image Builder.
Purpose:
- Gives Image Builder permission to:
    - Read resources
    - Create resources
    - Store images
Without Managed Identity, AIB cannot work.

#### RBAC (Role-Based Access Control)
Controls what Azure Image Builder can do.
Typical flow:
1. Create Managed Identity
2. Assign RBAC permissions
3. AIB uses those permissions

#### JSON Template
We customize a json template provided by Azure to define the things for our image.
Contains:
- OS image information
- Applications to install
- Customizations
- Output image settings
Think of it as:
> "Build me a Windows 10 image, install Office, configure settings, then save it."

#### Actual Flow
1. Connect to azure
2. Get resource providers for AIB
3. Create a resource group for Azure Image Builder
4. Create Managed Identity
5. Provide RBAC to Managed Identity
6. Assign the managed identity to AIB
7. Download and Customize the json for the AIB 
	1. OS
		1. We provide **Offer:** Windows 10
		2. We provide **SKU:** Enterprise 22H2
	2. Applications,
	3. Customizations
8. Deploy Image template (Creates Image builder configuration in Azure)
9. Start Image Build (Starts actual image creation)

#### Generation 1 vs Generation 2 Issue
- Some VM sizes support only certain generations.
- Example:
	- VM Size = Standard D2 v2
	- May not support Generation 2 images
- Result:
	- Deployment fails.

#### Troubleshooting
Go to azure > monitor > activity log to view errors
