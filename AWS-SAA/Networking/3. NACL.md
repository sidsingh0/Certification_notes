- Network access control list
- Can block/allow IPs
- It is just an additional firewall for the subnet level (One NACL per subnet)
- So now we have 2 layers of protection:
	- NACL 
	- Security group of each instance inside the Subnet
- It is stateless (meaning we have to put inbound and outbound rules), it goes line by line by order of ranking
- However SGs are stateful (if we allow inbound, outbound is automatically allowed), they check the request at once (koi allow rule hai jo is request pe apply hota hoga? hai? no issues sir andar jao)
	- SG can only allow, not deny, by default nothing is allowed in
	- One peculiar thing to note is, if we disable outbound to an IP, but enable inbound for that IP, we cannot send requests to that ip or initiate a connection
	  However, if the connection is requested from that ip side to our instance, our instance will be able to reply to that ip. 
- Rules:
	- We assign rules ranking 1-32766
	- 100 has higher precedence then 200
	- In case no rules match, denied *
- Most important usecase:
	- *Block any IP at subnet level*
